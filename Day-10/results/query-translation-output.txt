Explanation: this EF Core version does NOT silently run the whole filter
client-side. IsLongQuote() is a plain C# method with no known SQL translation,
so EF Core's query translator refuses to build the query at all and throws
InvalidOperationException at ToListAsync() time, before any rows are read.
